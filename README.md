В этом репозитории представлен сквозной сценарий работы с базой данных проката инструментов. Главная цель — показать, как отдельные запросы объединяются в перезапускаемую программу и как организовать обмен данными между СУБД и внешними файлами.
Что у нас тута?
pr15.sql — основной перезапускаемый скрипт. Он создает песочницу, демонстрирует работу с переменными (через CTE), обновляет каталог из массива данных и готовит данные для выгрузки.
tools_batch.csv — файл поставки новых инструментов от поставщика (3 позиции).
price_list.csv — итоговый прайс-лист каталога после всех операций импорта и обновления цен.
Как выполнить работу (на примере SQLite)
Подготовка базы. Для выполнения Части 1 создайте тестовую таблицу rentals с колонками id, tool_id, deposit и заполните её данными о залогах.
Запуск сценария. Откройте файл pr15.sql. Выполняйте его поэтапно:
Сначала Часть 1 (переменные через подзапросы/CTE).
Затем Часть 2 (создание таблиц demo_tools и tools_stage). Скрипт можно запускать многократно благодаря командам DROP TABLE IF EXISTS.
Импорт данных (Часть 4).
Очистите таблицу-посредник: DELETE FROM tools_stage;
Нажмите кнопку Import в интерфейсе редактора, выберите файл tools_batch.csv и убедитесь, что включена опция пропуска первой строки (заголовка).
Перенос в каталог. Выполните запрос переноса данных из staging-таблицы в основную с защитой от дублей по имени инструмента.
Выгрузка в CSV (Часть 5).
В консоли редактора введите команды:
.mode csv
.once price_list.csv
Выполните запрос выборки прайс-листа. Результат сохранится в файл.
